Облако:
1. Заменить сертификаты
2. Проверить версии изображений: web-admin - 1.1.4, server - 0.2.5
3. Перекинуть zip архив папки с бд FILES_PATH в /var/lib/gdmn-mob_db
4. Настроить новый IP и порты для https://server.gdmn.app. Порт 3653 - серверное приложение (https), порт 3655 - серверное приложение (http), порт 3654 - админка
5. Заполнить .env файл в корне проекта
6. Настроить архивирование бд

ПИ:
1. Обновить ПИ на всех базах
2. Проверить адрес сервера в конфигурации на всех базах

Мобильные приложения:
1. Собрать все приложения последних версий в папку и добавить на сайт
2. Выложить последние весрии на HUAWEI
